Jetson Orin'da PyTorch, TorchVision ve OpenCV (JetPack 6.1)

25 Kasım 2026

Önce bunu okuyun. Bu adımları Mart 2025'te JetPack 6.1 (Ubuntu 22.04, Python 3.10, CUDA 12.6) çalışan bir Jetson Orin için yazdım. O tarihte çalışır diye yayımladım. Bu sayfa için yeniden çalıştırmadım ve sürüm numaraları hızlı değişiyor. Aşağıdaki sabit sürümleri örnek sayın, önce NVIDIA'nın uyumluluk tablosuna bakın.

İş sırası

  1. JetPack'inize uyan NVIDIA PyTorch wheel'ini kurun.
  2. Uygun wheel yoksa PyTorch'u kaynaktan derleyin.
  3. TorchVision'ı o PyTorch sürümüne uygun derleyin.
  4. OpenCV'yi CUDA ile derleyin (hazır gelen sürümde GPU desteği yok).

1. Sistemi hazırlayın

Wheel yolu için en az 5 GB boş alan gerekir; kaynaktan derleme çok daha fazlasını ve sabrı ister.

sudo apt-get update && sudo apt-get upgrade -y
sudo apt-get install -y python3-pip libopenblas-dev libopenmpi-dev \
  libjpeg-dev zlib1g-dev libpng-dev python3-setuptools

Paket adları Ubuntu sürümleri arasında değişir. apt bir paketi bulamazsa zorlamayın, apt-cache search ile arayın.

2. NVIDIA wheel'i ile PyTorch

NVIDIA, Jetson için derlenmiş PyTorch wheel'leri yayımlıyor. JetPack ve CUDA sürümünüze uyanı NVIDIA indirme dizininden seçin (adlandırmayı kurulum rehberi açıklıyor), indirin ve kurun:

sudo -H pip3 install --upgrade pip
sudo -H pip3 install ./torch-2.5.0a0+872d972e41.nv24.08.17622132-cp310-cp310-linux_aarch64.whl   # example file name; use yours
python3 -c "import torch; print(torch.__version__, torch.cuda.is_available())"

Bir sürüm numarası ve True görmelisiniz. Sürüm JetPack'inize uymuyorsa ya da CUDA False diyorsa sonraki bölüme geçin.

3. Wheel uymuyorsa: PyTorch'u kaynaktan derleyin

Bu yedek yöntemdir ve yavaştır, çoğu zaman birkaç saat sürer. Derleme saat hızında takılmasın diye önce kartı yüksek performans moduna alın:

sudo nvpmodel -q                # show the current mode
sudo nvpmodel -m 0             # on many Orin images 0 is MAXN; check /etc/nvpmodel.conf for your model
sudo jetson_clocks             # pin clocks high while building

İlk taslağımda -m 0 ve -m 2 yorumları ters yazılmıştı. Mod numaraları Orin modellerine göre değişir; bir blog yazısındaki numaraya, bu yazı dahil, güvenmeyin, /etc/nvpmodel.conf dosyasına bakın.

Derleme seçeneklerini ayarlayın, depoyu çekin, etiketi seçin ve derleyin. TORCH_CUDA_ARCH_LIST, GPU'nuzun compute capability değeriyle eşleşmeli (Orin için 8.7).

export USE_NCCL=1
export USE_DISTRIBUTED=1
export USE_QNNPACK=0
export USE_PYTORCH_QNNPACK=0
export TORCH_CUDA_ARCH_LIST="8.7"   # Orin; see the compute capability table for other boards
export PYTORCH_BUILD_VERSION=2.5.0
export PYTORCH_BUILD_NUMBER=1
cd ~
git clone --recursive https://github.com/pytorch/pytorch.git
cd pytorch
git checkout v2.5.0
sudo apt-get install -y cmake ninja-build python3-dev libopenblas-dev libopenmpi-dev \
  libomp-dev libjpeg-dev libpng-dev libtiff-dev libpython3-dev \
  libavcodec-dev libavformat-dev libswscale-dev ccache
pip3 install --upgrade pip
pip3 install -r requirements.txt
pip3 install scikit-build ninja
python3 setup.py bdist_wheel      # can take several hours
pip3 install --no-cache-dir dist/torch-*.whl
python3 -c "import torch; print(torch.__version__, torch.cuda.is_available())"

4. TorchVision

Bunu yazdığımda JetPack 6.1 için hazır bir TorchVision wheel'i yoktu, bu yüzden kaynaktan derledim. Sürüm, kurduğunuz PyTorch ile eşleşmeli (uyumluluk tablosu); PyTorch 2.5.0, TorchVision 0.20.0 ile eşleşir.

sudo apt-get install -y cmake ninja-build gcc g++
cd ~
git clone https://github.com/pytorch/vision.git
cd vision
git checkout tags/v0.20.0
sudo -H python3 setup.py install
python3 -c "import torch, torchvision; print(torch.__version__, torch.cuda.is_available(), torchvision.__version__)"

CUDA için True ve eşleşen sürümler görmelisiniz. Derleme görüntü kütüphanelerinden şikâyet ederse önce libjpeg-dev, libpng-dev ve libtiff-dev kurun.

5. CUDA'lı OpenCV

İmajla gelen OpenCV çalışır ama CUDA desteği yoktur. GPU'yu kullanmak için kendiniz derlersiniz.

sudo sh -c "echo '/usr/local/cuda/lib64' >> /etc/ld.so.conf.d/nvidia-tegra.conf"
sudo ldconfig
sudo apt-get install -y build-essential cmake git unzip pkg-config zlib1g-dev \
  libjpeg-dev libpng-dev libtiff-dev libglew-dev libavcodec-dev libavformat-dev \
  libswscale-dev libgtk-3-dev python3-dev python3-numpy python3-pip \
  libxvidcore-dev libx264-dev libtbb-dev v4l-utils libv4l-dev gstreamer1.0-tools \
  libgstreamer-plugins-base1.0-dev libgstreamer-plugins-good1.0-dev \
  libopenblas-dev liblapack-dev libeigen3-dev gfortran libhdf5-dev

İlk listemde libfaac-dev, libdc1394-22-dev ve birkaç eski GTK ve codec paketi daha vardı. Bu sayfa için listeyi kısalttım: bazı adlar Ubuntu 22.04'te yok ve CUDA modülleri için gerekmiyor. Kısa liste benim düzenlemem ve test edilmedi; derlemenizin istediği paketleri geri ekleyin.

cd ~
OPENCV_VERSION=4.10.0    # example tag; use one release for both repositories
git clone --depth=1 --branch "$OPENCV_VERSION" https://github.com/opencv/opencv.git
git clone --depth=1 --branch "$OPENCV_VERSION" https://github.com/opencv/opencv_contrib.git

Bu rehberin ilk sürümü varsayılan dalı klonluyordu. Ana modüller ile opencv_contrib uyuşsun diye iki depoyu da aynı sürüm etiketine sabitleyin.

cd ~/opencv && mkdir -p build && cd build
cmake -D CMAKE_BUILD_TYPE=RELEASE \
  -D CMAKE_INSTALL_PREFIX=/usr/local \
  -D OPENCV_EXTRA_MODULES_PATH="$HOME/opencv_contrib/modules" \
  -D WITH_CUDA=ON -D CUDA_ARCH_BIN=8.7 \
  -D WITH_CUDNN=ON -D WITH_CUBLAS=ON \
  -D ENABLE_FAST_MATH=ON -D CUDA_FAST_MATH=ON -D OPENCV_DNN_CUDA=ON \
  -D WITH_GSTREAMER=ON -D WITH_FFMPEG=ON -D WITH_V4L=ON -D WITH_LIBV4L=ON \
  -D WITH_TBB=ON -D WITH_OPENMP=ON -D WITH_EIGEN=ON \
  -D OPENCV_ENABLE_NONFREE=ON \
  -D BUILD_TESTS=OFF -D BUILD_EXAMPLES=OFF \
  -D INSTALL_C_EXAMPLES=OFF -D INSTALL_PYTHON_EXAMPLES=OFF \
  -D PYTHON3_PACKAGES_PATH=/usr/lib/python3/dist-packages \
  -D OPENCV_GENERATE_PKGCONFIG=ON ..
make -j"$(nproc)"
sudo make install
sudo ldconfig

CUDA_ARCH_BIN=8.7 yalnız Orin içindir. Orijinalde -D OPENCV_EXTRA_MODULES_PATH=~/opencv_contrib/modules yazıyordu; kabuk eşittir işaretinden sonraki ~'yi açmaz, bu yüzden $HOME kullanın. 8 GB'lık bir kartta tam -j$(nproc) derlemesi belleği doldurabilir; ölürse iş sayısını düşürün ya da swap ekleyin.

python3 -c "import cv2; print(cv2.getBuildInformation())" | grep -i cuda

NVIDIA CUDA: YES ve CUDA sürümünü görmelisiniz.

6. İzleme ve temizlik

jtop (jetson-stats ile gelir) CPU, GPU, bellek ve gücü canlı gösterir.

sudo -H pip3 install -U jetson-stats
sudo reboot
# after the reboot:
jtop
sudo apt-get autoremove -y && sudo apt-get clean
rm -rf ~/opencv ~/opencv_contrib    # frees roughly 275 MB; keep them if you plan to rebuild

Bugün bunu izlemeden önce neye bakardım

  • JetPack sürümünüz ve NVIDIA'nın artık o sürüm için TorchVision wheel'i yayımlayıp yayımlamadığı.
  • Yukarıdakiler yerine NVIDIA'nın uyumluluk notlarındaki PyTorch ve TorchVision sürümleri.
  • NVIDIA'nın hazır Docker konteyneri bu yığını zaten veriyor mu. Çoğu zaman daha kısa yoldur.

İlk olarak Mart 2025'te Medium'da üç ayrı yazı olarak yayımlandı (PyTorch sorun giderme, PyTorch ve TorchVision, OpenCV). Burada birleştirilip düzeltildi; orijinal TorchVision yazısındaki adım numarası atlaması giderildi. JetPack 6.1 için yazıldı, bu sayfa için yeniden test edilmedi.
