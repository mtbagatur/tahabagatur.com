Field cases

Production failures and architecture trade-offs traced from symptom to measured evidence.

  • Slow LLM responses: the vendor's fix targeted the wrong component

    An approved concurrency test (180 requests, 0 errors) and vLLM metrics proved latency came from long-prompt prefill on a single GPU rather than auth replicas, unlocking a second model replica on allocated idle GPU capacity.

    Read case →

  • A recurring GPU-node outage traced to a silent NVMe hang

    A minute-by-minute timeline across Prometheus, kernel journal, and BMC logs traced repeated node freezes to an NVMe disk hanging silently in RAID1 while multipath kept requeueing I/O.

    Read case →

  • Monitoring a vendor-managed AI platform without installing agents

    A read-only Prometheus federation bridge over SSH (Python stdlib, systemd) brought a vendor-managed GPU cluster into central alerting while cutting ingested series from ~25,000 to ~1,900.

    Read case →

  • A domain-wide DNS move, decided on evidence

    Documented zone inventory and three migration paths with explicit trade-offs so the domain cutover to Cloudflare went through with zero downtime.
